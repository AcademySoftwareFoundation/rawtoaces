.. _task-examples:

Task examples
=============

Each page states one conversion or solve, then shows that same task in
C++ and Python. Shell is included when the command line can do it.
A build that cannot run a method says so next to that example.

The command line defaults to soft crop. The C++ and Python APIs default
to hard crop. File-conversion examples set the crop mode so the three
forms describe the same pixels.
